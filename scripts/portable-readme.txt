MINI BROWSER 1.8.0 - PORTABLE WINDOWS x64

GET STARTED
Extract the ZIP, then double-click Mini Browser.exe.
Keep every extracted file together in a writable folder.
No installation or Node.js is required.

USE THE BROWSER
Type an HTTP/HTTPS address and press Enter. There is no default web
search engine. Address suggestions match this profile's bookmarks and
history. The new tab page has an address field and bookmark shortcuts.
Drag an empty part of the tab strip to move; drag any edge to resize.
The three-dot menu contains Zoom, Find, Downloads, History, Bookmarks,
Print, Passwords, and Clear browsing data. Pin and Auto-hide controls
are buttons on the top tab strip.
Use the star to bookmark a page. Add shortcut saves an address directly.
The bookmark bar hides when empty; toggle it in the menu. Drag to reorder.
Start-page shortcuts scroll horizontally; the pale scrollbar appears on hover.
Right-click a shortcut or bookmark-bar entry and choose Edit to change it.
Icons support PNG/APNG, JPEG, GIF, WebP, AVIF, BMP, ICO/CUR, SVG and SVGZ,
including inline image icons. Animated icons use a static first frame.
Unreadable formats keep a letter fallback; JPEG XL, TIFF and HEIC are
not supported by the bundled Chromium image decoder.
Website controls stay clickable even when a site includes desktop-only
window-drag styles. Only the browser's own tab strip drags the window.
Voice/text, recording, WebSocket, streamed responses and file uploads use
Chromium's built-in browser APIs. Microphone and clipboard consent stay on.

TABS AND VIDEO
Use + for a new tab and x to close a tab. Right-click for Reload,
Duplicate, Pin tab, Mute, Close, and Close others. Pinned tabs stay first.
Drag tabs to reorder, detach into a window, or join a same-profile window.
Ordinary new-tab links create tabs; sized popups open real child windows.
Auto-hide controls hides the browser UI without changing the window size.
Move the mouse near its top edge to reveal the controls.
A video's fullscreen button fills the small floating window; the window
stays resizable. Esc exits video fullscreen. F11 fills the monitor.

PROFILES AND DATA
The profile button opens a vertical menu over the page without moving it.
Choosing an unopened profile opens a separate mini browser. Choosing an
already open profile only closes the picker. The original window stays
untouched. Profiles have separate cookies, cache, bookmarks, history,
passwords, website storage, and permissions. Drag profile cards to reorder.
Click a profile's initial or photo to choose a PNG, JPEG, or WebP picture.
A small square thumbnail stays locally saved; the original is unchanged.
Click the small x on its photo to remove it and return to initials.
Open website URLs and the active tab restore for that profile next time.
Forms and session storage do not restore after closing their tabs.
Data lives in .mini-browser beside Mini Browser.exe. No sync or analytics.
Saved passwords use Windows account encryption and cannot move to a
new Windows account or computer. Saving and filling require your choice.
Some custom or multistep login forms cannot be detected. Passwords stay
local; submitting a filled form sends them to that website as usual.
Clear browsing data lets you separately clear history, cache, cookies,
and saved passwords for the selected profile. Bookmarks remain saved.
Downloads save in the Windows Downloads folder without overwriting files.
The toolbar bubble has progress, cancel, open, and show-in-folder actions.
Common site access requests show a prompt; the site icon opens permissions.

CLOSE AND EXIT
Closing a window keeps Mini Browser running in the Windows system tray.
Double-click the tray icon, choose Open Mini Browser, or launch its shortcut
to reopen. Exit in the three-dot menu or tray menu quits the entire app.
Use Exit before moving the portable folder or changing its data files.

SHORTCUTS
Ctrl+L                 Address bar
Alt+Left / Right       Back / forward
Ctrl+R / F5            Reload or stop
Ctrl+T / W             New / close tab
Ctrl+Tab               Next tab (Shift for previous)
Ctrl+1-8 / 9           Numbered / last tab
Ctrl+Shift+T           Reopen closed tab
Ctrl+D                 Bookmark page
Ctrl+H                 Profile history
Ctrl+F                 Find (Enter next, Shift+Enter previous, Esc close)
Ctrl+Plus / Minus / 0  Active tab zoom in / out / reset
Ctrl+P                 Print active page
Ctrl+Shift+P           Keep on top
Ctrl+Shift+H           Auto-hide controls
F11                    Monitor fullscreen
Alt+Home               New tab page
Esc                    Exit video/fullscreen, reveal controls, stop loading

Extensions, sync, Google browser sign-in, external app links and direct
USB/HID/serial access are not supported. Some DRM or login services may
require a full browser.
